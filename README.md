# 🌤️ Weather & Environmental Analytics Dashboard

## 📌 Project Overview
An interactive dashboard for monitoring weather conditions, 7-day temperature forecasts, Air Quality Index (AQI), atmospheric pollutants, and environmental metrics across multiple cities.

## 🎯 Project Objectives
- Monitor current weather conditions and temperature.
- Analyze 7-day weather forecasts and rainfall probabilities.
- Track AQI and major air pollutants.
- Monitor humidity, wind speed, visibility, pressure, and UV index.
- Compare weather conditions across multiple cities.

## 🚀 How to Use
1. Clone or download this repository.
2. Open the `.pbix` file using Microsoft Power BI Desktop.
3. Explore weather conditions for Gurgaon, Chennai, and Hyderabad.
4. Analyze temperature trends, AQI, pollutants, and rainfall probabilities.
5. Use the dashboard to explore weather and environmental patterns.
