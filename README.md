🌤️ Weather & Environmental Analytics Dashboard

📌 Project Overview

The Weather & Environmental Analytics Dashboard is an interactive data analytics project designed to provide real-time meteorological metrics, weekly temperature forecasts, Air Quality Index (AQI) monitoring, and detailed atmospheric conditions across major cities. It provides key environmental and weather insights through modern UI cards, line trends, and pollutant level indicators.

🎯 Business Objectives

Monitor real-time temperature, current weather conditions, and last updated timestamps.

Track 7-day temperature forecast trends and daily high/low fluctuations.

Analyze Air Quality Index (AQI) and key atmospheric pollutants ($PM_{10}$, $PM_{2.5}$, $SO_2$, $O_3$, $CO$, $NO_2$).

Identify sunrise and sunset times along with weekly chance of rain probabilities.

Evaluate critical atmospheric indicators such as humidity, wind speed, visibility, pressure, UV index, and precipitation.

Provide multi-city weather tracking across cities like Gurgaon, Chennai, and Hyderabad.
